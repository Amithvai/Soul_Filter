# Soul Filter

Filter adblock harian untuk [Soul Browser](https://play.google.com/store/apps/details?id=com.mycompany.app.soulbrowser).
Format: Adblock Plus / EasyList. Sumber: [oisd](https://oisd.nl) & [ABPindo](https://github.com/ABPindo/indonesianadblockrules). Di-update otomatis oleh GitHub Actions tiap hari ±03.00 WIB.

## URL Filter (raw.githubusercontent.com)

| File | URL |
|---|---|
| oisd small | https://raw.githubusercontent.com/Amithvai/Soul_Filter/main/output/soul-oisd-small.txt |
| oisd big   | https://raw.githubusercontent.com/Amithvai/Soul_Filter/main/output/soul-oisd-big.txt |
| ABPindo    | https://raw.githubusercontent.com/Amithvai/Soul_Filter/main/output/soul-abpindo.txt |

## Cara pasang di Soul Browser

Settings → Adblock → nyalakan → Filter URL → tambahkan URL di atas.
**Pilih salah satu saja: small ATAU big** (big mencakup small).
Set auto-update = 1 hari.
